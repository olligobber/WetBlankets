# Wet Blankets

Proof of the solution to a sudoku in lean: [sudokupad.app/tdzmfngyfp](https://sudokupad.app/tdzmfngyfp).

I attempted to do this sudoku twice, but both times made a mistake leading to a contradiction. I had been thinking about using a proof assistant for a sudoku especially in the context of fog of war sudokus, which are particularly susceptible to guess and check methods, so decided to try it on this one.
